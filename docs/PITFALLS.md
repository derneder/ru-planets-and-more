# Грабли

Всё перечисленное — реальные ошибки, уже случившиеся в этом проекте.
Каждая стоила отдельного разбора, поэтому записано.

## 1. Двойной слеш в переносах строк

**Что произошло.** В файле диалогов Eneas переносы были записаны как `\\n`
(два слеша) вместо `\n` (один). В игре во всех 135 местах вместо перевода
строки отображался бы видимый текст `\n`.

**Почему не заметили сразу.** Вывод инструментов JSON-экранирован: то, что
на экране выглядит как `\\n`, в реальном файле является `\n`. Проверка
«сравним количество `\n`» тоже не помогла — подстрока `\n` содержится
внутри `\\n`, поэтому счётчики совпали.

**Как проверять правильно.** Считать оба варианта отдельно и сравнивать
байты, а не глазами по выводу терминала:

```python
s.count('\\n')    # один слеш + n
s.count('\\\\n')  # два слеша + n  ← этого быть не должно
```

`tools/check.py` делает это автоматически.

**Важно:** в разных файлах одного мода формат может отличаться. У Eneas
в `dialogue.cfg` был один слеш, а в `informatron.cfg` — тоже один, но
проверять надо каждый файл отдельно и воспроизводить как в оригинале.

## 2. Ключ `[mod-name]` должен быть внутренним именем мода

**Что произошло.** В `[mod-name]` было написано `title=...`, скопированное
из формата экспорта локализации. Название мода в списке модов не
переводилось вообще, хотя весь остальной перевод работал.

Правильно — ключом служит внутреннее имя мода:

```ini
[mod-name]
planetaris-arig=○ Planetaris: Ариг
```

**Та же ошибка встречается в самих модах:**
- `Cold_biters` — ключ был `Frost_biters` (осталось от переименования мода)
- `Abacayba` — ключ `Abacayba-Moon-of-Nauvis` через дефисы, а внутреннее
  имя через подчёркивания
- `Igrys` — секции `[mod-name]` нет даже в английской локализации

Внутреннее имя берите из имени папки мода, не из его локализации.

## 3. Опечатки в ключах английского оригинала

У `factorioplus` ключ записан как `Tarmac ` — с лишним пробелом. Из-за
этого название плитки не локализуется ни на один язык. В русском файле
ключ был написан правильно, поэтому диффер показал его как «лишний в RU»,
хотя на деле лишний пробел был в EN.

**Вывод:** если `gaps.py` показывает «есть в RU, но нет в EN» — не спешите
удалять, сначала посмотрите на пробелы и опечатки в английском ключе.

## 4. Мод обновился сильнее перевода

Hyarion 1.3.10 переработали: флюорит заменил прежние «самоцветы», появился
рефракционный генератор. Перевод, с которого начинали, был от более старой
версии — 32 ключа отсутствовали, 1 указывал на удалённый предмет.

**Вывод:** при обновлении оригинального мода прогоняйте `gaps.py` заново.

## 5. Собственные переводы тоже надо сверять

Ошибку «Собиратель лучей преломления» в предметах против «Коллектор» в
сущностях (один объект под двумя именами) нашли только на сплошной сверке —
и она была унаследована в наш собственный файл при дополнении чужого.

**Вывод:** `audit.py` прогонять и по своим файлам тоже.

## 6. Ложные срабатывания audit.py

Проверяются глазами, менять не нужно:

| Что показывает | Почему это нормально |
|---|---|
| «sector 5» → «в пятом секторе» | число прописью |
| «Set to zero» → «Установите 0» | слово против цифры |
| «10.000» → «10 000» | разделитель тысяч в русской типографике |
| `Cupriavidus necator` | научное видовое название |
| «Отвлекающая капсула» / «Отвлекатель» | предмет и сущность, как в ванили |
| «○ Абакайба» / «Абакайба» | название мода против названия планеты |
| «Ремкомплект X» / «Ремонт X» | предмет против технологии |

## 7. Структура архива для портала

Внутри zip всё должно лежать в одной папке `<name>_<version>`. Архив, где
файлы лежат в корне или в папке без версии, портал отклонит.
`tools/build.py` собирает правильно.

## 8. Дубли секций в одном файле

Если в файле дважды встречается `[entity-name]`, ключи из обоих блоков
подхватятся — это допустимо и удобно, когда правки дописываются в конец
файла отдельным блоком с комментарием. Но **дубли одного и того же ключа**
недопустимы: выиграет последний, и это будет неочевидно.
`tools/check.py` их ловит.
