# source-en

Рабочая папка для сверки. Сюда кладут `locale/en/*.cfg` (и `locale/ru/*.cfg`,
если перевод уже есть) из архивов чужих модов — по ним `tools/gaps.py` и
`tools/audit.py` проверяют наш перевод построчно.

**Содержимое папки намеренно не коммитится.** Это текст авторов
соответствующих модов, а не наш; распространять его вместе с этим
репозиторием мы не будем. В git попадает только этот файл.

Чтобы наполнить папку у себя, скопируйте нужные `.cfg` из установленных
модов — на Windows их архивы лежат в `%APPDATA%\Factorio\mods\`, внутри
каждого в папке `locale/`. Имя файла произвольное; удобно кодировать в нём
мод и версию:

```
en__planetaris-tellus_1_1_7.cfg
ru__planetaris-tellus_1_1_7.cfg
```

Дальше:

```bash
python3 tools/gaps.py  source-en/en__....cfg [source-en/ru__....cfg]
python3 tools/audit.py source-en/en__....cfg mod/locale/ru/имя-мода.cfg "Название"
```
